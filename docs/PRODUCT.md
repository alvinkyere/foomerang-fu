# PRODUCT — Foomerang

Status: Draft v0.1 (Milestone 0)

## Vision
Foomerang is a browser-based party gaming platform. A host opens it on a laptop/TV browser, picks a game, and players scan a QR code to turn their phones into low-latency controllers. No accounts, no installs, no pairing.

**Open → Pick game → Scan → Play.** Target: scan to controlling a character in under 10 seconds.

## Two products, one platform
| Name | Role |
|---|---|
| **Foomerang** | The console/platform: lobby, rooms, controllers, game SDK |
| **Foomerang Fu** | First flagship game: original top-down boomerang arena combat |

"Nintendo Switch seamless" is a *quality target*, not a V1 scope target.

## Creative constraint
Foomerang Fu is *mechanically inspired* by boomerang arena games. All art, characters, maps, audio, UI, naming and branding must be original. No copied assets or presentation.

## Users
- **Host**: person at the big screen; creates the room, starts matches.
- **Player**: person with a phone; joins, plays.

## Principles
1. Onboarding friction is the enemy.
2. Input must feel immediate; measure, never assume.
3. The platform knows nothing about any specific game.
4. Game feel (feedback, animation, audio, haptics) is a feature, not polish.

## Non-goals (until throwing a boomerang from a phone feels great)
Native apps, accounts, friends, online matchmaking, voice chat, achievements, cosmetics, payments, spectators, marketplace, user-created games, more than one game, complex backend infrastructure.

## Success criteria for the project
A demonstrable, measured, low-latency platform that turns arbitrary phones into controllers, a reusable game SDK, and one original shipped game proving it.
